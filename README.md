# Distribuidora Gas El Volcán

Página web para la **Distribuidora de Gas El Volcán**, empresa dedicada a la venta y distribución de gas licuado a domicilio en Chillán.

## Descripción

El proyecto permite a los clientes visualizar los productos disponibles y realizar pedidos de cilindros de gas.

La página busca facilitar la gestión de pedidos y mejorar el proceso de compra y entrega.

## Productos

* Gas 5 kg
* Gas 11 kg
* Gas 15 kg

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript

## Proyecto

Proyecto académico para la asignatura **DSY1104 – Desarrollo FullStack II**
